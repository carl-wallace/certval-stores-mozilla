The notice appears here rather than in each file because the contents of
this directory are binary DER and cannot carry a comment. MPL-2.0
Exhibit A provides for exactly this case.

172 root certificates from the Mozilla Root Store, one DER file each,
named after the CCADB certificate label with non-alphanumerics replaced
by `_`. Generated by `tools/refresh.py` from:

    https://ccadb.my.salesforce-sites.com/mozilla/IncludedRootCertificateReportPEMCSV

Snapshot 2026-08-13. Do not edit by hand — `tools/refresh.py` rewrites
this directory wholesale, and `src/generated.rs` indexes into it by
filename. Cross-check any refresh with `tools/verify_against_nss.py`
before committing.

See `NOTICE` at the repository root for full attribution, including the
CCADB data usage terms that apply alongside the MPL.
