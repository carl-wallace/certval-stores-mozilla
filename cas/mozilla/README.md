The notice appears here rather than in each file because the contents of
this directory are binary DER and CBOR and cannot carry a comment.
MPL-2.0 Exhibit A provides for exactly this case.

2,563 CCADB-disclosed intermediate CA certificates, one DER file each,
named by uppercase SHA-256 fingerprint, plus `mozilla.cbor` — the
certval store holding the partial-path graph over them. Reached only
through the `mozilla_cas` feature, which implies `mozilla_all`.

Generated by `tools/refresh_cas.py` from the union of:

    https://ccadb.my.salesforce-sites.com/mozilla/PublicAllIntermediateCertsWithPEMCSV
    https://ccadb.my.salesforce-sites.com/mozilla/MozillaIntermediateCertsCSVReport

The union matters: a set of technically-constrained sub-CAs appears only
in the second report. Generation runs to a fixed point and names whatever
certval cannot reach.

See `NOTICE` at the repository root for full attribution, including the
CCADB data usage terms that apply alongside the MPL.
